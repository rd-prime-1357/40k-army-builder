   doesn't). Same pattern held for Scintillating Legions, Legions of Excess, and Blood Legions on
   spot check.

   distinct `CD`-faction, `source_id 000000012` row for every one of them (11 direct hits on first

   In Terminator Armour — matched on a case-insensitive pass). None of these 21 CD-faction IDs are
   in `units.json` yet. Spot-checked 5 of the 21 against the supporting source files
   (`Datasheets_abilities`, `Datasheets_models`, `Datasheets_models_cost`, `Datasheets_options`,
   `Datasheets_unit_composition`, `Datasheets_wargear`) — all present, so the missing piece is
   pipeline work, not missing source material.

5. **Conclusion: S229's "data-only, tag and flip" plan was wrong about the size of the job.** The
   correct build is a pipeline run (`wahapedia_transform.py`, `loadout_parser.py`,
   `equipped_parser.py`, `convert_to_json.py`, `merge_factions.py`) against 21 new datasheet IDs to
   generate 21 new Chaos Daemons-block entries tagged `allied_group: "Shadow Legion Thralls"` —
   sized like a small faction build, not a two-file data edit. Hand-tagging the existing CSM entries
   would have meant hand-editing output-shaped data and shipping generic ability text where the real
   source has faction-flavored wording — both against standing practice.

6. **Stopped cleanly.** No change to `units.json`, `detachment_effects.json`, or
